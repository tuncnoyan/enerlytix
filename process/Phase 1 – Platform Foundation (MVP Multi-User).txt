Phase 1 – Platform Foundation (MVP Multi-User)
Goal: Move from a single-user application to a hosted multi-user application.
Features:

1.Authentication:
1.1. Login/logout
1.2. Password reset
1.3. User profile page

2. Invitations:

2.2. Invitation expiry

3.1. List users
3.2. Create user invitations
3.3. Enable/disable users
3.4. Rename users
3.5. Reset passwords
3.6. Delete users

4. Basic Roles
4.1. Admin
4.2. User
