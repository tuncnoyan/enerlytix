Phase 7 – Page-Level Review System
Goal: Allow reviewer collaboration.

Features:

1. Per report page/section:
1.1. Comments
- Comment Thread
- Author
- Timestamp

1.2. Validation Checkbox
- Validated

1.3. Auto-Unvalidate
- If page content changes: Validated = False

Example:
Page 3
Comment: "Please verify gas intensity figure."
[✓] Validated by Sarah Jones
